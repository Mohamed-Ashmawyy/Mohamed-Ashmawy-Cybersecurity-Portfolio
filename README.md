# Mohamed Ashmawy — Cybersecurity Portfolio

A dark, English-only portfolio for Mohamed Abdelmonem Ashmawy, Cybersecurity Analyst and Penetration Tester.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Local development

```bash
npm install --legacy-peer-deps
npm run dev
```

## Production build

```bash
npm run check
npm run build
```

The portfolio includes selected penetration-testing labs, a healthcare web/API security assessment, Huawei firewall hardening, security automation work, experience, credentials, and contact links.
